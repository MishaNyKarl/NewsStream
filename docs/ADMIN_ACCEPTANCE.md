# Проверка админки и автодеплоя

Автоматические тесты и серверные проверки выполняет разработчик. Пункты «с вашего устройства» оставлены владельцу — они зависят от его браузера и реальных финансовых параметров.

## Разработчик

- [x] Из main запускаются CI и деплой; PR запускает только проверки.
- [x] Проверяются полный набор тестов с PostgreSQL, Ruff, исходники на известные форматы секретов и Compose.
- [x] Сервер устанавливает именно SHA коммита; `.env` остаётся вне релиза.
- [x] Перед обновлением создаётся дамп БД; проверены здоровье bot/worker и возврат прежнего образа при ошибке.
- [x] SSH-ключ CI не открывает произвольную командную сессию.
- [x] Тесты админки проверяют вход, CSRF, ограничение попыток, сессии, одноразовые подтверждения и формулы.
- [x] На внешнем HTTPS-адресе доступны вход и все закрытые страницы после авторизации.
- [x] Анонимный доступ к статистике и перезапуску отклонён; выход закрывает сессию.
- [x] Статистика читается из рабочей PostgreSQL; отдельная SQL-роль не может удалять данные.
- [x] Статусы Docker и ресурсы сервера получены через настоящий host helper.
- [x] Контролируемый перезапуск через веб-интерфейс завершён; сервис снова healthy.
- [x] Push установил бот и админку из одного коммита, с отдельным постоянным томом административных данных.

## С вашего устройства

- [ ] Открыть адрес из файла доступа. При предупреждении о собственном сертификате сверить его SHA256 с файлом доступа.
- [ ] Войти, открыть обзор, пользователей, наблюдения, расходы, документацию; проверить удобство на телефоне.
- [ ] В расходах выбрать период и Telegram ID; открыть следующую страницу запросов.
- [ ] Сопоставить записанные расходы с кабинетом OpenRouter: старые данные не содержат признака «фактические/оценочные».
- [ ] В калькуляторе указать фактическую месячную долю VPS, прочие расходы, курс, бюджет LLM, число плательщиков, комиссию, налоги и желаемую маржу.
- [ ] Убедиться, что расчёт после обновления страницы сохранён. Рассмотреть сценарии числа пользователей; цена не должна приниматься автоматически за готовый тариф.
- [ ] Выйти и убедиться, что кнопка «назад» не открывает доступ к закрытым данным без нового входа.

Повторять перезапуск на живом боте ради отметки не требуется: разработчик проверяет его один раз в спокойный момент. Перезапуск может прервать текущую обработку. Документация по восстановлению и ограничениям — [ADMIN](ADMIN.md), [CI/CD](CI_CD.md), [эксплуатация](OPERATIONS.md).
