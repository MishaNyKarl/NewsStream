Формула и допущения

F = VPS + прочие расходы; L = месячный бюджет LLM × курс; N = плательщики; c = комиссия / 100; t = налоги / 100; m = маржа / 100.

Безубыточная цена = (F + L) / [N × (1 − c − t)]. Целевая цена = (F + L) / [N × (1 − c − t − m)]. Маржа — доля выручки после указанных затрат, а не наценка.

Сценарии сохраняют переменные расходы v = L/N на пользователя: затраты = F + v × новое N. При заданной цене P число плательщиков = округление вверх F / [P × (1 − c − t) − v], если знаменатель положителен.

Комиссии и налоги здесь считаются линейными долями валовой выручки, без порогов, вычетов и фиксированных сборов. Расходы бесплатных пользователей включайте в бюджет LLM; если они не растут пропорционально плательщикам, сценарии потребуют ручной корректировки. Это не налоговая консультация и не обещание идеального тарифа.

Ставки токенов используются только для альтернативной оценки исторических запросов. Бюджет LLM вводится отдельно и не переносится автоматически из неполного периода.
